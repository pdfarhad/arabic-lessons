# Topic chapters: a category beside the lessons, first used for numbers

User (2026-08-30): "make a separate chapter on numbers and their different forms in
arabic. i.e. numbering, ranking etc." — requested with the Unit 3 ingest, because
Unit 3's pages use numbers in three new ways (خَمْسُ غُرَفٍ، الدَّوْرُ الخامِسُ، الخَميس)
without explaining any of them.

**Decision.** Cross-unit topics get their own category, **Topic Chapters**
(`chapters/c00N-*.html`, own numbering, own nav group and index section), never a
lesson number — lesson numbers track the class's units and a topic page is not a
unit. First chapter: `c001-numbers`.

**Scope rule for a topic chapter.** Everything on a class page is taught in full.
Material that *completes a pattern the book has started* is included for
recognition, tagged `beyond the book` in the page (`.beyond` in arabic.css), and
marked ⟂ in the knowledge note — never drilled in the builder or MCQs. In c001 that
covers: صِفْر; the masculine side of polarity (ثَلاثَةُ أَوْلادٍ); 1–2 as post-noun
adjectives; ordinals 6th–10th; feminine counted forms 6–10 (reference table only).
This keeps to MISSION.md's "never pre-teach the next unit" while honouring the
user's ask for the *forms*, which the book alone does not make sense of.

**Also decided.** Polarity is taught by *showing* the ة move (reveal scene), not by
name first — "opposites" with the grammar term given once. The days of the week are
taught as number-derived (day 1–5 hidden in five names), which is the chapter's
mnemonic spine.
