# Mission set: spoken ability, class-owned syllabus

The mission is practical spoken ability following a taught class that uses
*Al-Arabiyyah Bayna Yadayk* Book 1 (see [[MISSION.md]]). The class owns the syllabus:
this workspace enhances each delivered unit (audio, flashcards, sentence builder,
per-line readers) and never pre-teaches upcoming units. Unit 2's drag-ins (possessive
suffixes ـي/ـه, gendered present verbs, في + place) are taught as fixed frames only,
with the full systems left until the class reaches them.
