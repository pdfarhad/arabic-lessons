5. Sentence shapes so far

shapeexamplemeaning
point + describeهَذا أَخي. هُوَ مُدَرِّسٌ.This is my brother. He is a teacher.
point + name + describeهَذا والِدي عَدْنان وَهُوَ مُهَنْدِسٌ.This is my father ʿAdnān, and he is an engineer.
person + في + place + verbسَعِيدٌ في الغُرْفَةِ يَقْرَأُ القُرْآنَ.Saʿīd is in the room reading the Qur'an.
this is THE oneهَذا هُوَ المِعْطَفُ.Here it is — the coat.
