# Mission: Arabic

## Why
Farhad is attending a taught Arabic class that uses *Al-Arabiyyah Bayna Yadayk* (Book 1).
The goal is **practical spoken ability** — to actually say and understand the language of
each chapter in real exchanges, not just recognise it on the page. The class owns the
syllabus; this workspace enhances each unit with audio, flashcards and sentence-building
practice, and never runs ahead of it.

## Success looks like
- Can perform each unit's dialogues from memory, aloud, at natural speed — both roles.
- Can build new grammatical sentences from a unit's frames (هذا أخي. هو مدرسٌ.) with
  correct gender agreement, without written prompts.
- Recalls each unit's vocabulary on flashcards (Arabic → meaning and meaning → Arabic).
- Keeps pace with the class comfortably week to week.

## Constraints
- Already reads and writes Arabic script fluently — **no script instruction, no
  transliteration crutch**. Vocalised Arabic + audio + English gloss only.
- Study happens between classes in short sessions; lessons must be quick wins.
- Syllabus is the class's, not ours: enhance the taught unit, never pre-teach the next.

## Out of scope
- Dialect (the book is MSA/fusha; stay with the book).
- Arabic handwriting/calligraphy practice.
- Grammar terminology beyond what a unit's frames need (no i'rab theory yet).
